shouldWarnAboutFSharpCoreRedirects targetProfiles createBindingRedirects

Full Usage: shouldWarnAboutFSharpCoreRedirects targetProfiles createBindingRedirects

Parameters:
    targetProfiles : TargetProfile list
    createBindingRedirects : BindingRedirectsSettings option

Returns: bool

Determines whether the "FSharp.Core references without redirects: force" warning should be emitted for a project that targets the given profiles and has the given resolved binding-redirect settings for its FSharp.Core reference. Binding redirects (and the App.config files they live in) are only relevant for projects that target the classic .NET Framework (net5.0 and later is modelled as DotNetFramework V5+ but is not .NET Framework) - .NET Core/.NET 5+ and netstandard-only projects use assembly unification via deps.json instead, so the warning would be noise there.

targetProfiles : TargetProfile list

Returns: bool
