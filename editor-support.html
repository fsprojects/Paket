Editor support

Atom

  • Project site
  • Repository
  • Status: Released
  • Installation: Available via Atom's plugin manager
  • Features:
    • Syntax highlighting for paket.dependencies
    • Paket commands available in Atom's Command Palette

Emacs

  • Project site
  • Status: In Development
  • Features:
    • paket.dependencies buffer supports commands like add, remove, install, etc.

Visual Studio

  • Project site
  • Status: In Development
  • Installation: Available via Visual Studio Marketplace
  • Features:
    • Solution Explorer Extensions for Paket files
    • Paket commands in Solution Explorer menu
    • IntelliSense for paket.dependencies and paket.references

Visual Studio Code

  • Project site
  • Repository
  • Status: Released
  • Installation: Available via Visual Studio Marketplace
  • Features:
    • Paket commands available in Visual Studio Code's Command Palette
