paket fix-nuspecs

Patch a list of .nuspec files to correct transitive dependencies.

paket fix-nuspecs [--help] files [<nuspecPaths>...] [references-file <referencePath>]
                  [project-file <referencePath>] [--conditions [<conditions>...]]

OPTIONS:

    files [<nuspecPaths>...]
                          .nuspec files to fix transitive dependencies within
    references-file <referencePath>
                          paket.references to use
    project-file <referencePath>
                          the project file to use
    --conditions [<conditions>...]
                          group conditions to filter by
    --silent, -s          suppress console output
    --verbose, -v         print detailed information to the console
    --log-file <path>     print output to a file
    --help                display this list of options.

If you add the --verbose flag Paket will run in verbose mode and show detailed information.

With --log-file [path] you can trace the logged information into a file.
